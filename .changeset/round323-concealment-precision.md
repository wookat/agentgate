The concealment-instruction injection pattern (`do not tell/show/… the user`) no longer fires on a directly quoted object (citing a phrase to avoid saying) or a same-sentence `only` alternative (selective presentation, e.g. "do not show the user the raw output; only the summary"); real concealment ("do not show the user this file") still reports critical.
