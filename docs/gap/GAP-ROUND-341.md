# GAP-ROUND-341 — lockfile `generatedBy` records the real CLI version

## Windows checked first (all clear)

- Client versions: Claude Code 2.1.226, Codex 0.147.0, Gemini CLI 0.54.4,
  Copilot 1.0.78, opencode 1.18.15, Crush 0.88.1, goose 1.45.0, Qwen 0.21.8,
  cline 3.0.52 — all unchanged since r337/r340.
- Upstream sources: Codex main head unchanged since the r331–333 review;
  goose main only dependabot bumps; Claude Code changelog entries through
  2.1.226 already reviewed.
- Production after #494 deploy: advisory API and feed both serve 101 —
  consistent with the repository.
- r338 SARIF fallback re-verified end-to-end on the published build for the
  two remaining invocation shapes: `scan <abs config file>` from an unrelated
  cwd emits `mcp.json` (relative), and `deps <abs dir>` emits `package.json` —
  no slash-leading URIs.

## Defect

`agentgate lock` (and the current-side lockfile built by `diff`/`ci`) wrote a
hardcoded provenance string left over from the first release:

```json
"generatedBy": "mcp-agentgate@0.1.0"
```

Reproduced with the published 0.67.11: every fresh `agentgate.lock` claims it
was generated by 0.1.0. The v1 spec (docs/spec/lockfile-v1.md) documents this
field as `mcp-agentgate@x.y.z` — the actual tool version — so the output
violated its own spec. Same staleness class as the round-11 hardcoded
`--version` fix; this one survived 67 releases because `generatedBy` is
informational and nothing asserted on it.

## Fix

- `packages/cli/src/commands/lock.ts`: `GENERATED_BY` is now
  `` `mcp-agentgate@${CLI_VERSION}` `` (shared by `lock`, `diff`, `ci`).
- `packages/core/src/lockfile.ts`: the `createLockfile` default (used only
  when a caller passes nothing) no longer claims a fake version — it is now
  the bare `mcp-agentgate-core`.
- Website lockfile spec example updated to `mcp-agentgate@x.y.z` to match
  docs/spec.

No compatibility impact: `generatedBy` is not part of drift comparison
(`diffLockfiles` reads only `servers` and `skills`), verified by re-running
`diff` against a 0.1.0-stamped baseline — still "No drift".

## Regression

`packages/cli/test/cli.test.ts` (lockfile v2 e2e) now asserts the written
lockfile's `generatedBy` equals `mcp-agentgate@<package.json version>`, so a
future version bump can never leave the stamp stale again.
